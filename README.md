# Sharpsheep Digital Consultancy — Website Starter

A responsive, mobile-first static website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure, service catalogue, contact links, SEO metadata and starter ProfessionalService schema.
- `styles.css` — responsive visual design, brand colours, layouts, accessibility and motion preferences.
- `script.js` — mobile navigation, service filtering/search, WhatsApp enquiry messages, share button and current year.

## Run locally
Open `index.html` in a modern browser. For a more realistic local web-server preview, use VS Code's Live Server or run `python -m http.server` from this folder.

## Important launch checklist
1. Replace the temporary typographic SDC mark with the official logo asset when supplied.
2. Replace the abstract director initials illustration with the approved director portrait and approved biography.
3. Replace the short blog summaries with the three full, client-approved SEO articles.
4. Check the FAQ draft against the client's five approved Q&As.
5. Confirm all service descriptions, prices, terms, timelines and any regulated-service disclaimers with the client.
6. Update `og:url` and the canonical domain after the final domain is purchased. The current domain value is a suggested placeholder.
7. Add a canonical link and sitemap/robots.txt after the production domain is confirmed.
8. If analytics are approved, add the chosen analytics provider's tag and consent/privacy wording as appropriate.
9. Confirm the WhatsApp business number, direct line, email and social profile before launch.
10. Test the final website on real mobile devices, keyboard navigation, and a slow connection.

## Notes
- No fake testimonials are included. The reviews section explicitly says testimonials are coming soon.
- Prices and service categories follow the supplied brief.
- Blog and FAQ copy are short draft summaries because the full approved text was referenced in the brief but not included in the supplied file.
- This is a static front-end prototype. It does not store enquiries, process payments, or provide a CMS.
